# Public mathematics consumer

An ordinary console project references Mathematics without friend-assembly access. It exercises the public `Geometry2D` / `Geometry3D` entry points, generic integer/decimal/BigInteger geometry, float BCL versus double FMA arithmetic, streaming struct sinks, and SIMD span operations. It also exercises explicit `SGray<byte>`, `SGray<double>`, `SGrayAlpha<decimal>`, `SRgb<int>`, `SBgra<double>` layouts, `RawRgb565` packed bits, typed component/packed batches, `SHsla<T>` / `SHsva<T>`, the explicit encoded → linear → premultiply → unpremultiply → encoded pipeline. Raw packed words expose FromSrgb / FromLinear and InterpretSrgb / InterpretLinear without hidden transfer. Both Srgb and Linear families retain custom numeric storage. Raw alpha is supplied explicitly; UNORM normalization adds opaque normalized alpha only at that named boundary. A reference-containing decimal-backed custom `INumber<T>` proves ordinary consumer support without assuming blittable storage.

```sh
dotnet run --project samples/Lumyte.Mathematics.Sample -c Release
```

Assertions fail the process if a public operation returns an unexpected result. Shape-specific operations remain available on their value types. Arithmetic and boundary policies are explicit in method names, including `ContainsPolygonClosed`, `ContainsHalfOpenEdges`, `TransformAffineFused`, `TransformAffineChecked`, and BCL single-precision helpers.

The sample also checks `CssColors.Red`, `CornflowerBlue`, `Transparent`, immutable keyword enumeration and named lookup. These are semantic eight-bit sRGB `SRgba8` values: `SRgba<float> color = CssColors.Red;` automatically normalizes each byte by 255f, without gamma decoding or premultiplication. `new SRgba8(255, 128, 0)` defaults alpha to 255; `default(SRgba8)` is transparent black. `ToNormalized<double>()` selects another result type; an explicit reverse cast validates unit components and quantizes nearest-even, never clamps HDR. General `SRgba<T>` semantics are unchanged: `CssColors.Red.ToCodes().ConvertChecked<float>()` preserves raw 255f, while `ToCodes().NormalizeUnorm<float>(255)` explicitly normalizes raw codes. Common storage accepts finite raw/HDR values; drawing and UI validate unit colors when accepting them. Contextual colors and CSS parsing are outside the catalog.

Drawing consumers can use `canvas.FillRect(rect, CssColors.Red)` or `PaintGraph2D.Solid(CssColors.CornflowerBlue)` directly. UI properties likewise accept `widget.Fill = CssColors.Red`. Generated UI factories accept `UiArgument<SRgba<float>>`, so C# cannot chain both user-defined conversions: use `SRgba<float> color = CssColors.Red; Compose.Rectangle(fill: color)` or `Compose.Rectangle(fill: UiArgument<SRgba<float>>.Constant(CssColors.Red))`. Use an explicit generic type for signals and animation, e.g. `Signal.Create<SRgba<float>>(CssColors.Red)` and `new Tween<SRgba<float>>(...)`; nullable keys use `AnimationKey<SRgba<float>?>`. No generic runtime conversion operator or Mathematics-to-UI dependency is added.
