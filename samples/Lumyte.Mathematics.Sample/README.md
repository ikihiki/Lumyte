# Public mathematics consumer

An ordinary console project references Mathematics without friend-assembly access. It exercises the public `Geometry2D` / `Geometry3D` entry points, generic integer/decimal/BigInteger geometry, float BCL versus double FMA arithmetic, streaming struct sinks, and SIMD span operations. It also exercises explicit `Gray<byte>`, `Gray<double>`, `GrayAlpha<decimal>`, `Rgb<int>`, `Bgra<double>` layouts, `Rgb565` packed bits, typed component/packed batches, `Hsla<T>` / `Hsva<T>`, sRGB transfer and alpha association. Raw alpha is supplied explicitly; UNORM normalization adds opaque normalized alpha only at that named boundary. A reference-containing decimal-backed custom `INumber<T>` proves ordinary consumer support without assuming blittable storage.

```sh
dotnet run --project samples/Lumyte.Mathematics.Sample -c Release
```

Assertions fail the process if a public operation returns an unexpected result. Shape-specific operations remain available on their value types. Arithmetic and boundary policies are explicit in method names, including `ContainsPolygonClosed`, `ContainsHalfOpenEdges`, `TransformAffineFused`, `TransformAffineChecked`, and BCL single-precision helpers.

The sample also checks `CssColors.Red`, `CornflowerBlue`, `Transparent`, immutable keyword enumeration and named lookup. These are semantic eight-bit sRGB `Srgb8` values: `Rgba<float> color = CssColors.Red;` automatically normalizes each byte by 255f, without gamma decoding or premultiplication. `new Srgb8(255, 128, 0)` defaults alpha to 255; `default(Srgb8)` is transparent black. `ToNormalized<double>()` selects another result type; an explicit reverse cast validates unit components and quantizes nearest-even, never clamps HDR. General `Rgba<T>` semantics are unchanged: `CssColors.Red.ToCodes().ConvertChecked<float>()` preserves raw 255f, while `ToCodes().NormalizeUnorm<float>(255)` explicitly normalizes raw codes. Common storage accepts finite raw/HDR values; drawing and UI validate unit colors when accepting them. Contextual colors and CSS parsing are outside the catalog.

Drawing consumers can use `canvas.FillRect(rect, CssColors.Red)` or `PaintGraph2D.Solid(CssColors.CornflowerBlue)` directly. UI properties likewise accept `widget.Fill = CssColors.Red`. Generated UI factories accept `UiArgument<Rgba<float>>`, so C# cannot chain both user-defined conversions: use `Rgba<float> color = CssColors.Red; Compose.Rectangle(fill: color)` or `Compose.Rectangle(fill: UiArgument<Rgba<float>>.Constant(CssColors.Red))`. Use an explicit generic type for signals and animation, e.g. `Signal.Create<Rgba<float>>(CssColors.Red)` and `new Tween<Rgba<float>>(...)`; nullable keys use `AnimationKey<Rgba<float>?>`. No generic runtime conversion operator or Mathematics-to-UI dependency is added.
