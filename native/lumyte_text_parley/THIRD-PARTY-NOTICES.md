# Parley native dependencies: third-party notices

<!-- markdownlint-disable MD010 -->

This file records the registry crates resolved by `Cargo.lock` for the Parley trial.
It includes build-time tools as well as runtime dependencies; not every listed crate is linked into every target.
Upstream license files are reproduced without changing their terms. Alternative license choices remain as stated upstream.
The Lumyte bridge itself is not assigned a new license by this document.

Update this file when the locked dependency graph changes. Font fixture licenses are distributed alongside the fonts.
The .NET Fallout runner copies the exact Rust toolchain's `COPYRIGHT-library.html` alongside the native artifact as
`RUST-STANDARD-LIBRARY-NOTICES.html`; the native and Browser targets include that companion file in output and publish.
Keep platform-runtime notices as well when distributing those runtime components separately.
The Rust project describes its notices in [COPYRIGHT](https://github.com/rust-lang/rust/blob/1.99.1/COPYRIGHT).

The csbindgen archive does not include its license text; its upstream MIT license is reproduced from
[Cysharp/csbindgen LICENSE](https://github.com/Cysharp/csbindgen/blob/24bcf088fd6ae06a61f7c929f3fe203cdc055482/LICENSE).
